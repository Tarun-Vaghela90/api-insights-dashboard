# API Insights Dashboard

A premium dark-themed dashboard for visualizing product data from the DummyJSON API.

## Features
- React + TypeScript + Vite
- Tailwind CSS
- TanStack Query for API state management
- Recharts-powered analytics
- Responsive dark SaaS dashboard
- Product search and category insights

## Getting started

```bash
npm install
npm run dev
```

Then open `http://localhost:5173`.

## Production build

```bash
npm run build
```
